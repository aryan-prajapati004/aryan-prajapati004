<summary><b>&nbsp;🎧 Unified Intelligent System for Audio Inference</b> &nbsp;—&nbsp; FastAPI · Whisper · pyannote · PyTorch · Gemini &nbsp;<sub>Team project, 2026</sub></summary>
<br/>

A system that answers questions about an audio file by analysing speech, speakers, and non-speech sounds together.

| Stream | Model | Purpose |
|---|---|---|
| Audio events | CNN14 / PANN | 527-class AudioSet classification |
| Transcription | Whisper (Groq) | Speech-to-text with hallucination gate |
| Speaker identity | pyannote | Diarization across speakers |

All three fused into a per-upload **SQLite timeline**. Follow-up queries previously re-ran the full pipeline (~30s each); session caching cut that to **under 2s** — a >90% reduction.

`FastAPI` `PyTorch` `CNN14/PANN` `Whisper` `pyannote` `LangChain` `Gemini` `SQLite`
